# 📊 لوحة تحليل المبيعات باستخدام Excel

مشروع لتحليل بيانات المبيعات باستخدام **Microsoft Excel**، ويضم مصنفًا رئيسيًا للوحة المعلومات إلى جانب ملفات بيانات المبيعات والبيانات المرجعية المرتبطة بها.

## 🎯 هدف المشروع

تنظيم بيانات المبيعات واستكشافها بطريقة تساعد على فهم أداء المبيعات ومقارنة النتائج عبر أبعاد مختلفة، مثل الفروع والعملاء والمنتجات والعلامات التجارية وطرق الدفع.

## 🔍 أسئلة يمكن استكشافها

من خلال فحص البيانات والمصنف، يمكن دراسة أسئلة مثل:

- ما الفروع الأعلى من حيث المبيعات؟
- كيف تتغير المبيعات بين عامي 2023 و2024؟
- ما مدى انتشار طرق الدفع المختلفة؟
- ما المنتجات والعلامات التجارية المرتبطة بأعلى المبيعات؟
- كيف يمكن مقارنة المبيعات بحسب العملاء؟

هذه أسئلة تحليلية مقترحة وليست نتائج مؤكدة. لم تُذكر أرقام أو استنتاجات محددة دون التحقق منها من داخل المصنف.

## 🧰 الأداة المستخدمة

- **Microsoft Excel** — لفتح ملفات البيانات ومصنف لوحة المعلومات واستكشاف النتائج.

## 🚀 طريقة الاستخدام

1. نزّل المستودع من GitHub أو افتح الملف الذي تحتاجه من قائمة الملفات.
2. افتح [مصنف لوحة المعلومات](./Dashboard%20Salesxlsx.xlsx) باستخدام Microsoft Excel.
3. لاستكشاف البيانات المصدرية، افتح ملف المبيعات أو الملف المرجعي المطلوب.
4. إذا طلب المصنف تحديث بيانات من ملفات خارجية، فتحقّق من مسارات الملفات وإعدادات الاتصال قبل التحديث.

## 📝 ملاحظات

- يتضمن المستودع ملفات Excel بصيغة `.xlsx`.
- تعتمد النتائج التي يمكن استخلاصها على البيانات والحقول الموجودة فعليًا داخل الملفات.
- لم تُدرج أرقام للمبيعات أو الأرباح أو ترتيب للفروع في هذا التوثيق؛ ينبغي حسابها والتحقق منها قبل عرضها باعتبارها نتائج للمشروع.
- لم تُضف صورة معاينة للوحة المعلومات لعدم وجود صورة مستقلة لها ضمن ملفات المستودع الحالية.
