# 📊 لوحة تحليل المبيعات | Sales Dashboard

مشروع لتحليل بيانات المبيعات وعرضها بصورة تساعد على استكشاف أداء الفروع والجوانب المرتبطة بالمبيعات، بالاعتماد على ملفات **Microsoft Excel** الموجودة في هذا المستودع.

> **ملاحظة حول نطاق المشروع:** الملفات المتاحة حاليًا في المستودع هي ملفات Excel بصيغة `.xlsx`. لا يوجد ملف Power BI بصيغة `.pbix` ضمن الملفات الحالية، لذلك لا يفترض هذا التوثيق وجود تقرير Power BI جاهز.

## 🎯 فكرة المشروع

يهدف المشروع إلى تنظيم بيانات المبيعات والبيانات المرجعية المرتبطة بها، وإتاحة استكشافها من خلال ملف لوحة المعلومات الموجود في المستودع.

ومن الأسئلة التي يمكن دراسة بيانات المشروع للإجابة عنها:

- ما الفروع الأعلى من حيث المبيعات؟
- كيف تختلف نتائج المبيعات بين الفروع؟
- ما طرق الدفع المستخدمة، وكيف يتوزع التعامل بينها؟
- كيف يمكن استكشاف البيانات بحسب العملاء والمنتجات والعلامات التجارية؟
- هل تتوفر بيانات تسمح بمقارنة الربح بين الفروع؟

هذه **أسئلة تحليلية مقترحة وليست نتائج رقمية مؤكدة**. لم تُذكر أرقام أو استنتاجات محددة هنا لأنها تحتاج إلى فحص المصنف وحساب النتائج الفعلية.

## 🧰 الأدوات والملفات

- **Microsoft Excel** — لفتح ملفات البيانات ومصنف لوحة المعلومات واستكشاف محتواها.
- ملفات Excel منفصلة لبيانات المبيعات والبيانات المرجعية المرتبطة بها.

لم تُدرج أدوات أو تقنيات أخرى على أنها مستخدمة فعليًا؛ إذ لا يمكن تأكيد استخدامها من أسماء الملفات وحدها.

## 🔎 نطاق التحليل

توضح أسماء الملفات المتاحة أن المستودع يضم بيانات مبيعات لعامي 2023 و2024، إلى جانب ملفات منفصلة للفروع والعلامات التجارية والعملاء والمنتجات وطرق الدفع.

يمكن استخدام هذه الملفات لاستكشاف المقارنات المناسبة بين أبعاد البيانات، بعد التأكد من الحقول الموجودة داخل كل ملف وطريقة ارتباطها ببيانات المبيعات.

## 🚀 طريقة الاستخدام

1. نزّل المستودع من GitHub أو افتح الملف المطلوب مباشرة من صفحة الملفات.
2. افتح [مصنف لوحة المعلومات](./Dashboard%20Salesxlsx.xlsx) باستخدام Microsoft Excel.
3. لاستكشاف الملفات المصدرية، افتح ملف المبيعات أو الملف المرجعي المناسب من الجدول أعلاه.
4. إذا احتاج المصنف إلى تحديث بيانات مرتبطة بملفات خارجية، فتحقّق من مسارات المصادر وإعدادات الاتصال قبل تنفيذ التحديث.

## 📌 ملاحظات

- لا يتضمن المستودع حاليًا ملف `.pbix`؛ لذلك لا يمكن فتح نسخة Power BI من خلال الملفات الحالية.
- لا يعرض هذا الملف أرقامًا للمبيعات أو الأرباح أو ترتيبًا للفروع؛ يجب استخراج هذه النتائج والتحقق منها من المصنف قبل توثيقها.
- لم تُضف صورة للوحة المعلومات لأن صورة معاينة مستقلة غير موجودة ضمن ملفات المستودع الحالية.
