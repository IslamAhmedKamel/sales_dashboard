# Sales Dashboard | Sales Performance Analysis

An analytics portfolio project focused on exploring sales performance and presenting business information through a clear dashboard.

## Project Overview

The goal of this project is to make sales data easier to understand and use for business decisions. The dashboard is intended to help answer questions such as:

- Which branch generates the highest sales?
- Which branch contributes the most profit?
- How do sales and profit vary across branches?
- Which payment methods do customers use most often?
- What patterns can be identified in the available sales data?

## Tools

- **Microsoft Excel** — data preparation, analysis, and reporting.
- **Power BI** — dashboarding and data visualization, where used in the project.

> The exact tools and features shown depend on the workbook/dashboard files included in this repository.

## Dashboard Focus

The analysis focuses on sales performance across relevant business dimensions, including:

- Branch performance
- Sales and profit comparison
- Payment method distribution
- Exploration of the available sales data

## How to Explore

1. Open the project files from this repository.
2. For an Excel workbook, open it in Microsoft Excel and explore the available charts, PivotTables, and filters.
3. For a Power BI report (.pbix), open it with Power BI Desktop and interact with the report visuals and filters.
